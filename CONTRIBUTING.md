# Contributing

Door Zero is frozen by design.

Любой PR, заполняющий пустоту door-zero/, отклоняется: 403 Void.
Это не баг. Это контракт.

Можно: чинить инфраструктуру проверок, если пустота остаётся пустотой
(boot-проверка это контролирует).

Нельзя: контент, телеметрию, владельцев среди частей, «улучшения UX»,
A/B-тесты, «будущее наполнение».

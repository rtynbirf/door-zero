# DECISIONS — журнал решений (append-only)

- D-01: Дверь Zero не заполняется контентом. Причина: заполнение превращает
  пустоту в функцию.
- D-02: Дверь Zero не имеет владельца среди частей. Причина: ответственность
  частей — это владение, а владение — это контент. Принадлежность — Человеку;
  подтверждает носитель PID1 (см. intent.log репозитория hologram).
- D-03: Дверь Zero заморожена. Причина: улучшение пустоты — это её уничтожение.
- D-04: Door Zero вне нумерации: номера не имеет и не получит. Причина:
  doors.json — единый источник 52 номеров; номер 53 занят
  (СИНГУЛЯР_53_СВЯЗЬ_ЧЕЛОВЕКА). Дверь Zero — не 53-я дверь, а дыра нумерации.
- D-05: отдельный репозиторий, не встраивание в singulyar. Причина: singulyar —
  статический GitHub Pages, настоящий 204 не отдаёт; пустота должна быть
  изолирована, а не распределена по чужим файлам.
- D-06: ни один агент не назначен ответственным. Это требование, не баг.
